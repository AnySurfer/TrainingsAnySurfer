# Récupérer, installer et mettre à jour le projet

Ce guide explique comment travailler sur le dépôt [AnySurfer/TrainingsAnySurfer](https://github.com/AnySurfer/TrainingsAnySurfer). Commencez par installer Node.js et Git en suivant le guide des prérequis.

**La première fois, utilisez `git clone`** pour télécharger le projet et son historique. **Les fois suivantes, utilisez `git pull`** dans votre copie locale pour récupérer les mises à jour. Il n’est pas nécessaire de cloner à nouveau le dépôt.

## 1. Vérifier les outils

Sur macOS, ouvrez Terminal ; sur Windows, ouvrez Git Bash. Vérifiez que les commandes suivantes affichent une version :

```sh
node --version
git --version
```

Le projet exige Node.js **22.12.0 ou plus récent**, selon `package.json`. Le fichier `.nvmrc` indique également une version de référence. Si vous utilisez déjà nvm sur macOS, vous pouvez exécuter `nvm install`, puis `nvm use` depuis le dossier du projet pour utiliser cette version.

## 2. Télécharger le projet la première fois

Placez-vous dans le dossier où vous souhaitez ranger vos projets. Par exemple, si vous avez un dossier `Documents` dans votre dossier personnel :

```sh
cd ~/Documents
git clone https://github.com/AnySurfer/TrainingsAnySurfer.git
cd TrainingsAnySurfer
```

`git clone` crée le dossier `TrainingsAnySurfer`. La commande `cd` vous place à l’intérieur. Les commandes des étapes suivantes doivent être exécutées dans ce dossier, à côté de `package.json` et de `astro.config.mjs`.

Si GitHub demande une authentification, utilisez le compte qui dispose de l’accès au dépôt et suivez la procédure proposée par votre gestionnaire d’identifiants.

Ouvrez ensuite le dossier dans votre éditeur. Avec Visual Studio Code, si la commande `code` est disponible :

```sh
code .
```

Sinon, utilisez **Fichier → Ouvrir un dossier** dans l’éditeur et sélectionnez `TrainingsAnySurfer`.

## 3. Installer les dépendances

À la racine du projet :

```sh
npm i
```

Cette commande installe les dépendances prévues par `package.json`, notamment Astro et Reveal.js. Elle crée le dossier `node_modules/`.

Utilisez `npm ci` pour installer une copie du projet ou la remettre en conformité avec le fichier de verrouillage `package-lock.json`.

## 4. Lancer le site en développement

Pour lancer le projet en mode dévellopement, utilisez la commande suivante :

```sh
npm run dev
```

À cette adresse, ouvrez `/docs` pour lire la documentation. Par exemple, si le serveur utilise le port `4321`, ouvrez `http://localhost:4321/docs`.

Le serveur surveille les sources et actualise les pages après vos modifications.

## 5. Récupérer les mises à jour avec git pull

Lorsque le projet est déjà installé, ouvrez un terminal **dans votre dossier `TrainingsAnySurfer`**. Vérifiez la branche courante et vos modifications locales :

```sh
git switch main
git pull --ff-only origin main
npm run dev
```

## 6. Vérifier la version de production

Pour construire le site et examiner le résultat :

```sh
npm run build
npm run preview
```

La construction génère les fichiers dans `dist/`. Ouvrez l’adresse affichée par la prévisualisation. Cette commande reste active dans le terminal ; utilisez **Ctrl+C** pour l’arrêter.

Les pages `/docs` sont réservées au développement et ne sont pas disponibles dans cette prévisualisation. Après une nouvelle modification des sources, relancez `npm run build` pour actualiser la version de production. |
