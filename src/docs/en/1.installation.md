# Get, install and update the project

This guide explains how to work with the [AnySurfer/TrainingsAnySurfer](https://github.com/AnySurfer/TrainingsAnySurfer) repository. Start by installing Node.js and Git using the prerequisites guide.

**Use `git clone` the first time** to download the project and its history. **Use `git pull` afterwards**, inside your local copy, to retrieve updates. You do not need to clone the repository again.

## 1. Check your tools

On macOS, open Terminal; on Windows, open Git Bash. Check that each command displays a version:

```sh
node --version
git --version
```

The project requires Node.js **22.12.0 or later**, according to `package.json`. The `.nvmrc` file also specifies a reference version. If you already use nvm on macOS, run `nvm install`, then `nvm use` inside the project folder to use that version.

## 2. Download the project for the first time

Open the folder where you want to keep your projects. For example, if your home folder contains a `Documents` folder:

```sh
cd ~/Documents
git clone https://github.com/AnySurfer/TrainingsAnySurfer.git
cd TrainingsAnySurfer
```

`git clone` creates the `TrainingsAnySurfer` folder. `cd` moves you into it. Run the commands in the following steps from this folder, alongside `package.json` and `astro.config.mjs`.

If GitHub asks you to sign in, use the account with access to the repository and follow your credential manager's instructions.

Next, open the folder in your editor. With Visual Studio Code, if the `code` command is available:

```sh
code .
```

Otherwise, use **File → Open Folder** in your editor and select `TrainingsAnySurfer`.

## 3. Install dependencies

From the project root:

```sh
npm i
```

This installs the dependencies specified in `package.json`, including Astro and Reveal.js. It creates `node_modules/` directory

Use `npm ci` to install a project copy or bring its dependencies into line with the lockfile `package-lock.json`.

## 4. Start the development site

To launch the project in development mode, use the following command:

```sh
npm run dev
```

At that address, open `/docs?lang=en` to read the documentation in English. For example, on port `4321`, open `http://localhost:4321/docs?lang=en`.

The server watches source files and refreshes pages after changes.

## 5. Get updates with git pull

Once the project is installed, open a terminal **inside your `TrainingsAnySurfer` folder**. Check the current branch and your local changes:

```sh
git switch main
git pull --ff-only origin main
npm run dev
```

## 6. Check the production version

To build the site and inspect the result:

```sh
npm run build
npm run preview
```

The build generates files in `dist/`. Open the address printed by the preview command. This command stays active in the terminal; use **Ctrl+C** to stop it.

The `/docs` pages are development-only and are not available in this preview. After changing source files again, rerun `npm run build` to update the production version.

To learn about pages, components, layouts and directories, continue with **Understanding the AnySurfer project** using the next-guide link.
