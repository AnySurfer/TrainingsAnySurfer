# UI components

Components in `src/components/ui/` are automatically imported with the `Ui` prefix: use `Slide.astro` as `<UiSlide />`. Example usage:

```astro
<UiTwoColumnSlide title="Compare">
  <p slot="left">Before</p>
  <p slot="right">After</p>
</UiTwoColumnSlide>
```

A **slot** receives child content; `slot="left"` sends it to the named `left` slot. Props marked `?` are optional. Components do not automatically forward extra HTML attributes to their root element.

## Presentations

Use these within the Reveal.js context provided by `LayoutSlides.astro`. This layout already includes `UiDeck`: do not nest another deck.

| Component          | Props               | Slots                    | Purpose                                                                                        |
| ------------------ | ------------------- | ------------------------ | ---------------------------------------------------------------------------------------------- |
| `UiDeck`           | None                | Default                  | Wraps slides in `.reveal` and `.slides` containers. Used in presentation layouts.              |
| `UiChapter`        | `id: string`        | Default                  | Chapter section with a unique anchor; expects child slides, navigated vertically in Reveal.js. |
| `UiSlide`          | `title?: string`    | Default, `notes`         | Slide section; displays an `h2` when the title is nonempty.                                    |
| `UiTwoColumnSlide` | `title?: string`    | `left`, `right`, `notes` | Section with two equal, vertically centered columns below an optional `h2`. No default slot.   |
| `UiNote`           | None                | Default                  | Reveal.js notes in `aside.notes`; wraps plain text in a `p` and preserves supplied HTML.       |
| `UiCode`           | `language?: string` | Default                  | `pre > code` block with `data-trim` and a `language-{language}` class when provided.           |

### Slide and notes

```astro
<UiChapter id="introduction">
  <UiSlide title="Objectives">
    <p>Understand users’ needs.</p>
    <UiNote slot="notes">Ask about the group’s expectations.</UiNote>
  </UiSlide>
</UiChapter>
```

### Two columns

`UiTwoColumnSlide` creates a complete slide and already includes the `<section>` element: use it directly in the deck or a `UiChapter`, without wrapping it in another slide section. When nonempty, the `title` prop creates an `<h2>` heading above the two columns.

```astro
<UiTwoColumnSlide title="Compare">
  <Fragment slot="left">
    <h3>Before</h3>
    <p>The initial content.</p>
  </Fragment>
  <p slot="right">The improved content.</p>
  <UiNote slot="notes">Explain the differences.</UiNote>
</UiTwoColumnSlide>
```

`Fragment` groups several elements in a slot without adding an HTML container. Put notes in `notes`, outside the columns. The component fills the slide height; check for overflow. Although its interface extends `HTMLAttributes<'section'>`, only `title` is used: `id`, `class` and other attributes are not rendered on the section.

### Code

```astro
<UiCode language="html">{'<button>Submit</button>'}</UiCode>
```

For a multiline example, use `is:raw`:

```astro
<UiCode language="html" is:raw>
  <label for="name">Name</label>
  <input type="text" id="name" name="name" autocomplete="name">
</UiCode>
```

Pass code as text to display its tags. Syntax highlighting depends on the Reveal.js Highlight integration and its available languages.

- [Reveal.js code block documentation](https://revealjs.com/code/)
- [Languages supported by Highlight.js](https://highlightjs.readthedocs.io/en/latest/supported-languages.html)

## Page elements

| Component           | Props                                                          | Slots   | Purpose                                                                                                                                                                                         |
| ------------------- | -------------------------------------------------------------- | ------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `UiHead`            | `title: string`, `description?: string` (default: `AnySurfer`) | Default | `head` element with title, metadata, favicon and `robots="nofollow, noindex"`. The slot adds head elements. Used in all layouts.                                                                |
| `UiHeaderLogo`      | `lang?: 'fr' \| 'en' \| 'nl'`                                  | None    | Localized logo and alternative text; links to the site root using `BASE_URL`. Otherwise uses `Astro.currentLocale`, then falls back to French. Used in layouts other than presentation layouts. |
| `UiFooter`          | `class?: string` (default: `site-footer`)                      | None    | AnySurfer footer linking to its website in a new tab. A supplied class replaces the default class. Used in layouts other than presentation layouts.                                             |
| `UiSmallAnySurfer`  | None                                                           | None    | Small AnySurfer name in a paragraph, with colors adapted to light or dark mode. Used in title slides (`Title.astro`).                                                                           |
| `UiTableOfContents` | `title: string`, `chapters: { id: string; title: string }[]`   | None    | Ordered navigation to chapter anchors; renders nothing when `chapters` is empty. Used in `LayoutSyllabus.astro`.                                                                                |

```astro
<UiTableOfContents
  title="Contents"
  chapters={[{ id: 'introduction', title: 'Introduction' }]}
/>
```

Each `id` must match an existing anchor. The component uses the fixed identifier `syllabus-toc-title` for its heading: include it only once per page.

## Resources page

`UiTrainingResources` takes a `training` prop containing JSON metadata and `sections`. It includes `Layout.astro` and generates navigation, anchors and numbering for visible sections. Empty lists are hidden. Data is validated by `src/lib/training-resources.ts`.

The `heading` slot customizes the page heading with an `<h1>`; other slots are named in the data to receive custom Astro content. See **Common actions** for the JSON format.

```astro
---
import training from '@data/intro-training-resources.json'
---

<UiTrainingResources training={training} />
```

## Training catalogs

| Component                  | Props                         | Slots | Source and behavior                                                                                                                                                               |
| -------------------------- | ----------------------------- | ----- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `UiTrainingList`           | `lang?: 'fr' \| 'nl' \| 'en'` | None  | Internal `trainings` array; links to slide decks and their syllabuses. Without `lang`, shows all available languages; otherwise filters the list. Used on slide deck index pages. |
| `UiTrainingResourcesIndex` | `lang: 'fr' \| 'en' \| 'nl'`  | None  | Complete page including `Layout.astro`; filters `src/data/training-pages.json` by language and sorts resources by title. Used on training index pages.                            |

```astro
<UiTrainingList lang="en" />
```

Use `UiTrainingResourcesIndex` directly in a page, without another layout:

```astro
<UiTrainingResourcesIndex lang="en" />
```

Both catalogs use `BASE_URL` for links but do not create the linked pages. They have separate sources: updating one does not update the other.
