# UI-componenten

Componenten in `src/components/ui/` worden automatisch geïmporteerd met het voorvoegsel `Ui`: gebruik `Slide.astro` als `<UiSlide />`. Gebruiksvoorbeeld:

```astro
<UiTwoColumnSlide title="Vergelijken">
  <p slot="left">Voor</p>
  <p slot="right">Na</p>
</UiTwoColumnSlide>
```

Een **slot** ontvangt onderliggende inhoud; `slot="left"` stuurt die naar het benoemde slot `left`. Props met `?` zijn optioneel. Componenten geven extra HTML-attributen niet automatisch door aan hun hoofdelement.

## Presentaties

Gebruik deze componenten binnen de Reveal.js-context van `LayoutSlides.astro`. Deze layout bevat al `UiDeck`: voeg geen tweede deck binnenin toe.

| Component          | Props               | Slots                    | Functie                                                                                                   |
| ------------------ | ------------------- | ------------------------ | --------------------------------------------------------------------------------------------------------- |
| `UiDeck`           | Geen                | Standaard                | Omhult dia’s met de containers `.reveal` en `.slides`. Gebruikt in presentatielayouts.                    |
| `UiChapter`        | `id: string`        | Standaard                | Hoofdstuksectie met een uniek anker; verwacht onderliggende dia’s, verticaal doorloopbaar in Reveal.js.   |
| `UiSlide`          | `title?: string`    | Standaard, `notes`       | Diasectie; toont een `h2` als de titel niet leeg is.                                                      |
| `UiTwoColumnSlide` | `title?: string`    | `left`, `right`, `notes` | Sectie met twee even brede, verticaal gecentreerde kolommen onder een optionele `h2`. Geen standaardslot. |
| `UiNote`           | Geen                | Standaard                | Reveal.js-notities in `aside.notes`; omhult gewone tekst met een `p` en behoudt aangeleverde HTML.        |
| `UiCode`           | `language?: string` | Standaard                | Blok `pre > code` met `data-trim` en de klasse `language-{language}` als een taal is opgegeven.           |

### Dia en notities

```astro
<UiChapter id="introduction">
  <UiSlide title="Doelstellingen">
    <p>De behoeften van gebruikers begrijpen.</p>
    <UiNote slot="notes">Vraag naar de verwachtingen van de groep.</UiNote>
  </UiSlide>
</UiChapter>
```

### Twee kolommen

`UiTwoColumnSlide` maakt een volledige dia en bevat al het element `<section>`: gebruik de component rechtstreeks in de presentatie of een `UiChapter`, zonder een extra diasectie eromheen. Als de prop `title` niet leeg is, maakt die een kop `<h2>` boven de twee kolommen.

```astro
<UiTwoColumnSlide title="Vergelijken">
  <Fragment slot="left">
    <h3>Voor</h3>
    <p>De oorspronkelijke inhoud.</p>
  </Fragment>
  <p slot="right">De verbeterde inhoud.</p>
  <UiNote slot="notes">Leg de verschillen uit.</UiNote>
</UiTwoColumnSlide>
```

`Fragment` groepeert meerdere elementen in een slot zonder een HTML-container toe te voegen. Plaats notities in `notes`, buiten de kolommen. De component vult de hoogte van de dia; controleer op overlopende inhoud. Hoewel de interface `HTMLAttributes<'section'>` uitbreidt, wordt alleen `title` gebruikt: `id`, `class` en andere attributen worden niet op de sectie weergegeven.

### Code

```astro
<UiCode language="html">{'<button>Bevestigen</button>'}</UiCode>
```

Gebruik `is:raw` voor een voorbeeld met meerdere regels:

```astro
<UiCode language="html" is:raw>
  <label for="name">Naam</label>
  <input type="text" id="name" name="name" autocomplete="name">
</UiCode>
```

Geef code als tekst door om de tags te tonen. Syntaxkleuring hangt af van de Highlight-integratie van Reveal.js en de beschikbare talen.

- [Documentatie over codeblokken in Reveal.js](https://revealjs.com/code/)
- [Talen die Highlight.js ondersteunt](https://highlightjs.readthedocs.io/en/latest/supported-languages.html)

## Pagina-elementen

| Component           | Props                                                            | Slots     | Functie                                                                                                                                                                                                                    |
| ------------------- | ---------------------------------------------------------------- | --------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `UiHead`            | `title: string`, `description?: string` (standaard: `AnySurfer`) | Standaard | `head` met titel, metadata, favicon en `robots="nofollow, noindex"`. Het slot voegt elementen aan de head toe. Gebruikt in alle layouts.                                                                                   |
| `UiHeaderLogo`      | `lang?: 'fr' \| 'en' \| 'nl'`                                    | Geen      | Logo en alternatieve tekst in de gekozen taal; link naar de hoofdmap van de site met `BASE_URL`. Gebruikt anders `Astro.currentLocale`, met Frans als terugval. Gebruikt in layouts voor andere pagina’s dan presentaties. |
| `UiFooter`          | `class?: string` (standaard: `site-footer`)                      | Geen      | AnySurfer-voettekst met een link naar de website in een nieuw tabblad. Een opgegeven klasse vervangt de standaardklasse. Gebruikt in layouts voor andere pagina’s dan presentaties.                                        |
| `UiSmallAnySurfer`  | Geen                                                             | Geen      | Kleine AnySurfer-naam in een alinea, met kleuren voor een licht of donker thema. Gebruikt in titeldia’s (`Title.astro`).                                                                                                   |
| `UiTableOfContents` | `title: string`, `chapters: { id: string; title: string }[]`     | Geen      | Geordende navigatie naar hoofdstukankers; toont niets als `chapters` leeg is. Gebruikt in `LayoutSyllabus.astro`.                                                                                                          |

```astro
<UiTableOfContents
  title="Inhoud"
  chapters={[{ id: 'introduction', title: 'Inleiding' }]}
/>
```

Elke `id` moet naar een bestaand anker verwijzen. De component gebruikt de vaste identifier `syllabus-toc-title` voor de kop: voeg de component slechts één keer per pagina toe.

## Opleidingscatalogi

| Component                  | Props                         | Slots | Bron en gedrag                                                                                                                                                                                           |
| -------------------------- | ----------------------------- | ----- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `UiTrainingList`           | `lang?: 'fr' \| 'nl' \| 'en'` | Geen  | Interne array `trainings`; links naar presentaties en hun syllabussen. Zonder `lang` worden alle beschikbare talen getoond; anders wordt de lijst gefilterd. Gebruikt op indexpagina’s van presentaties. |
| `UiTrainingResourcesIndex` | `lang: 'fr' \| 'en' \| 'nl'`  | Geen  | Volledige pagina met `Layout.astro`; filtert `src/data/training-pages.json` op taal en sorteert het materiaal op titel. Gebruikt op indexpagina’s van opleidingen.                                       |

```astro
<UiTrainingList lang="nl" />
```

Gebruik `UiTrainingResourcesIndex` rechtstreeks in een pagina, zonder extra layout:

```astro
<UiTrainingResourcesIndex lang="nl" />
```

Beide catalogi gebruiken `BASE_URL` voor links, maar maken de gekoppelde pagina’s niet aan. Hun bronnen zijn afzonderlijk: een wijziging in de ene werkt de andere niet bij.

Referentie: [Astro-componenten, props en slots](https://docs.astro.build/en/basics/astro-components/).
