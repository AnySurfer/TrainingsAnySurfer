Kleur & contrast

Kleurgebruik

Gebruik niet alleen kleur om informatie over te brengen.

body {
 filter : grayscale(100%);
}

Contrast

  • Tekst kleiner dan 24px: minimum 4,5:1
  • Tekst groter dan 24px: minimum 3:1
  • Vetgedrukte tekst van minstens 18,5px: minimum 3:1
  • User interface components: minimum 3:1
The ratio between sizes in points and CSS pixels is 1pt = 1.333px, therefore 14pt and 18pt are equivalent to approximately 18.5px and 24px.
