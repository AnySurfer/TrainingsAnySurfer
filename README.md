# Installation and prerequisites

## Prerequisites

- **Node.js**, install via https://nodejs.org .
- **Git** to clone the repository.

## Installation

1. Clone the repository and open a terminal in the project root.

2. Install dependencies from the lockfile:

   ```sh
   npm i
   ```

3. Start the development server in the background:

   ```sh
   npm run dev
   ```

   The site is available at `http://localhost:4321` by default.

# Deployments

`.github/workflows/deploy.yml` builds the site and publishes it to GitHub Pages
on every push to `main`. It can also be triggered manually on `main`.

The Astro configuration automatically sets the site URL and repository prefix
for GitHub Pages.

# Commands

## Development examples

The `/fr/exemples` page is available only with `astro dev`. Edit
`src/dev/exemples.astro` to add examples. Its route is registered only in
development and is not generated by `astro build` or published to GitHub Pages.

Run all commands from a terminal in the project root:

| Command                       | Action                                                                    |
| ----------------------------- | ------------------------------------------------------------------------- |
| `npm ci`                      | Installs dependencies from the lockfile                                   |
| `npm run dev -- --background` | Starts the local development server in the background at `localhost:4321` |
| `npm run astro -- dev status` | Checks the background development server's status                         |
| `npm run astro -- dev logs`   | Shows the background development server's logs                            |
| `npm run astro -- dev stop`   | Stops the background development server                                   |
| `npm run build`               | Builds the production site in `./dist/`                                   |
| `npm run preview`             | Previews the production build locally before deployment                   |

# Documentation

## Printable syllabi

The introduction syllabus is available at `/fr/syllabi/intro/`, with the same
content as `/fr/intro/` and visible speaker notes. Use its print button to print
on A4 paper or save a PDF from the browser.

To create another syllabus, wrap shared slide components in
`src/layouts/LayoutSyllabus.astro`. Pass `title`, `lang`, an optional
`slidesHref`, and optional `chapters` entries (`id`, `title`) for the table of
contents. Keep presentation instructions and cover slides out of the syllabus.
The introduction shares its content through `src/components/fr/intro/Content.astro`.

See the [Astro documentation](https://docs.astro.build).
