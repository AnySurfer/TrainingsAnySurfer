## Français

### 1. À quoi servent ces outils ?

**Node.js** exécute du JavaScript sur votre ordinateur. **npm**, fourni avec les installateurs Node.js, permet de gérer les dépendances des projets. **Git** suit l’historique des fichiers. **GitHub** héberge les dépôts Git en ligne et facilite la collaboration. Node.js n’est pas nécessaire pour utiliser Git.

Vous aurez besoin d’un accès Internet et d’un éditeur de texte. Sur Mac, ouvrez **Terminal** ; sur Windows, utilisez **Git Bash** après l’installation de Git. Tapez les commandes une par une, puis appuyez sur Entrée. Exécutez les commandes du projet dans son dossier. Remplacez les noms, emails et URL d’exemple par vos valeurs.

### 2. Installer Node.js et Git

#### Sur macOS

1. Sur la [page Node.js](https://nodejs.org/en/download), choisissez **LTS**, macOS et l’installateur **`.pkg`** adapté à votre Mac (Apple Silicon/ARM64 ou Intel/x64).
2. Ouvrez le fichier et suivez l’installation.
3. Pour installer Git, ouvrez Terminal et exécutez :

```sh
xcode-select --install
```

Acceptez l’installation des outils Apple et attendez la fin. S’ils sont déjà installés, passez à la vérification. Si vous utilisez déjà Homebrew, `brew install git` est une autre possibilité. [Référence Git pour macOS](https://git-scm.com/install/mac).

#### Sur Windows

1. Sur la [page Node.js](https://nodejs.org/en/download), choisissez **LTS**, Windows et l’installateur **`.msi`** adapté au PC (généralement x64 ; ARM64 sur les machines ARM).
2. Suivez l’installation et gardez npm et l’ajout au **PATH** activés.
3. Téléchargez et installez [Git pour Windows](https://git-scm.com/install/windows). Gardez les options par défaut, notamment Git Credential Manager si proposé.
4. Ouvrez **Git Bash** depuis le menu Démarrer.

#### Vérifier sur les deux systèmes

Fermez et rouvrez le terminal après les installations :

```sh
node --version
npm --version
git --version
```

Chaque commande doit afficher une version. Si une commande est introuvable, vérifiez l’installation et le PATH. Choisissez la version LTS proposée au moment du téléchargement ; aucun numéro précis n’est nécessaire pour cet exercice.

### 3. Créer un compte GitHub

1. Allez sur [GitHub](https://github.com/) et cliquez sur **Sign up**.
2. Suivez les étapes pour choisir un identifiant, fournir votre email et définir un mot de passe unique.
3. Validez votre adresse email via le message reçu.
4. L’offre **Free** suffit pour ce guide. Activez l’authentification à deux facteurs dans **Settings → Password and authentication**, et conservez les codes de récupération.

[Référence : démarrer avec un compte GitHub](https://docs.github.com/en/get-started/onboarding/getting-started-with-your-github-account).

### 4. Configurer son nom et son email dans Git

```sh
git config --global user.name "Prénom Nom"
git config --global user.email "vous@example.com"
git config --global --get user.name
git config --global --get user.email
```

`--global` applique ces valeurs à vos dépôts pour ce compte utilisateur sur cet ordinateur. Pour une identité différente dans un projet, exécutez les deux premières commandes dans son dossier sans `--global`.

Le nom identifie l’auteur des commits ; il peut différer de votre identifiant GitHub. L’email doit être associé à votre compte GitHub pour que les commits vous soient attribués. Pour préserver votre adresse personnelle, copiez votre adresse **noreply** exacte depuis **GitHub → Settings → Emails**. Cette configuration ne vous connecte pas à GitHub. Références : [nom](https://docs.github.com/en/get-started/git-basics/setting-your-username-in-git) et [email](https://docs.github.com/en/account-and-profile/how-tos/email-preferences/setting-your-commit-email-address).

## English

### 1. What are these tools for?

**Node.js** runs JavaScript on your computer. **npm**, included with the Node.js installers, manages project dependencies. **Git** tracks file history. **GitHub** hosts Git repositories online and supports collaboration. You do not need Node.js to use Git.

You need Internet access and a text editor. On Mac, open **Terminal**; on Windows, use **Git Bash** after installing Git. Run commands one at a time and press Enter. Run project commands inside the project folder. Replace example names, emails and URLs with your own values.

### 2. Install Node.js and Git

#### On macOS

1. On the [Node.js download page](https://nodejs.org/en/download), choose **LTS**, macOS and the **`.pkg`** installer for your Mac (Apple Silicon/ARM64 or Intel/x64).
2. Open the file and follow the installer.
3. To install Git, open Terminal and run:

```sh
xcode-select --install
```

Accept the Apple tools installation and wait for it to finish. If already installed, continue to verification. If you already use Homebrew, `brew install git` is another option. [Git for macOS reference](https://git-scm.com/install/mac).

#### On Windows

1. On the [Node.js download page](https://nodejs.org/en/download), choose **LTS**, Windows and the **`.msi`** installer matching your PC (usually x64; ARM64 for ARM devices).
2. Follow the installer, keeping npm and the **PATH** option enabled.
3. Download and install [Git for Windows](https://git-scm.com/install/windows). Keep the default options, including Git Credential Manager if offered.
4. Open **Git Bash** from the Start menu.

#### Verify on either system

Close and reopen your terminal after installation:

```sh
node --version
npm --version
git --version
```

Each command should print a version. If a command cannot be found, check installation and PATH. Choose the LTS version available when you download; this exercise does not require a specific version number.

### 3. Create a GitHub account

1. Go to [GitHub](https://github.com/) and click **Sign up**.
2. Follow the steps to choose a username, provide an email and set a unique password.
3. Verify your email using the message you receive.
4. **Free** is sufficient for this guide. Enable two-factor authentication under **Settings → Password and authentication**, and keep your recovery codes.

[Reference: getting started with a GitHub account](https://docs.github.com/en/get-started/onboarding/getting-started-with-your-github-account).

### 4. Configure your Git name and email

```sh
git config --global user.name "First Last"
git config --global user.email "you@example.com"
git config --global --get user.name
git config --global --get user.email
```

`--global` applies these settings to repositories for your operating-system user on this computer. For a different identity in one project, run the first two commands inside its folder without `--global`.

The name identifies the commit author and may differ from your GitHub username. Use an email associated with your GitHub account so commits are attributed to you. For privacy, copy your exact **noreply** address from **GitHub → Settings → Emails**. These settings do not sign you into GitHub. References: [name](https://docs.github.com/en/get-started/git-basics/setting-your-username-in-git) and [email](https://docs.github.com/en/account-and-profile/how-tos/email-preferences/setting-your-commit-email-address).

## Nederlands

### 1. Waarvoor dienen deze tools?

**Node.js** voert JavaScript uit op je computer. **npm**, meegeleverd met de Node.js-installatieprogramma’s, beheert projectafhankelijkheden. **Git** houdt de geschiedenis van bestanden bij. **GitHub** bewaart Git-repositories online en maakt samenwerken gemakkelijker. Je hebt Node.js niet nodig om Git te gebruiken.

Je hebt internettoegang en een teksteditor nodig. Open op Mac **Terminal**; gebruik op Windows **Git Bash** nadat je Git hebt geïnstalleerd. Voer de opdrachten één voor één uit en druk op Enter. Voer projectopdrachten uit in de projectmap. Vervang voorbeeldnamen, e-mailadressen en URL’s door je eigen gegevens.

### 2. Node.js en Git installeren

#### Op macOS

1. Kies op de [Node.js-downloadpagina](https://nodejs.org/en/download) **LTS**, macOS en het **`.pkg`**-installatieprogramma voor je Mac (Apple Silicon/ARM64 of Intel/x64).
2. Open het bestand en volg de installatiestappen.
3. Open Terminal en voer voor Git deze opdracht uit:

```sh
xcode-select --install
```

Bevestig de installatie van de Apple-tools en wacht tot die klaar is. Zijn ze al geïnstalleerd, ga dan verder met de controle. Gebruik je al Homebrew, dan is `brew install git` een alternatief. [Git voor macOS](https://git-scm.com/install/mac).

#### Op Windows

1. Kies op de [Node.js-downloadpagina](https://nodejs.org/en/download) **LTS**, Windows en het **`.msi`**-installatieprogramma voor je pc (meestal x64; ARM64 voor ARM-computers).
2. Volg de installatiestappen en laat npm en de **PATH**-optie ingeschakeld.
3. Download en installeer [Git voor Windows](https://git-scm.com/install/windows). Behoud de standaardopties, inclusief Git Credential Manager als die wordt aangeboden.
4. Open **Git Bash** via het Startmenu.

#### Controleren op beide systemen

Sluit de terminal na de installatie en open hem opnieuw:

```sh
node --version
npm --version
git --version
```

Elke opdracht moet een versienummer tonen. Wordt een opdracht niet gevonden, controleer dan de installatie en PATH. Kies de LTS-versie die bij het downloaden beschikbaar is; deze oefening vereist geen specifiek versienummer.

### 3. Een GitHub-account aanmaken

1. Ga naar [GitHub](https://github.com/) en klik op **Sign up**.
2. Volg de stappen: kies een gebruikersnaam, geef je e-mailadres op en stel een uniek wachtwoord in.
3. Bevestig je e-mailadres via het ontvangen bericht.
4. **Free** volstaat voor deze gids. Schakel tweestapsverificatie in via **Settings → Password and authentication** en bewaar je herstelcodes.

[Bron: aan de slag met een GitHub-account](https://docs.github.com/en/get-started/onboarding/getting-started-with-your-github-account).

### 4. Je naam en e-mailadres in Git instellen

```sh
git config --global user.name "Voornaam Achternaam"
git config --global user.email "jij@example.com"
git config --global --get user.name
git config --global --get user.email
```

`--global` past deze instellingen toe op de repositories van jouw gebruikersaccount op deze computer. Wil je voor één project een andere identiteit gebruiken, voer dan de eerste twee opdrachten in de projectmap uit zonder `--global`.

De naam geeft de auteur van commits aan en mag verschillen van je GitHub-gebruikersnaam. Gebruik een e-mailadres dat aan je GitHub-account is gekoppeld, zodat commits aan jou worden toegeschreven. Voor privacy kun je je exacte **noreply**-adres kopiëren uit **GitHub → Settings → Emails**. Deze instellingen melden je niet aan bij GitHub. Bronnen: [naam](https://docs.github.com/en/get-started/git-basics/setting-your-username-in-git) en [e-mailadres](https://docs.github.com/en/account-and-profile/how-tos/email-preferences/setting-your-commit-email-address).
