# Composants UI

Les composants de `src/components/ui/` sont importés automatiquement avec le préfixe `Ui` : `Slide.astro` s’utilise avec `<UiSlide />`. Exemple d’utilisation :

```astro
<UiTwoColumnSlide title="Comparer">
  <p slot="left">Avant</p>
  <p slot="right">Après</p>
</UiTwoColumnSlide>
```

Un **slot** reçoit le contenu enfant ; `slot="left"` l’envoie au slot nommé `left`. Les props marquées `?` sont facultatives. Les composants ne transmettent pas automatiquement les attributs HTML supplémentaires à leur élément racine.

## Présentations

À utiliser dans le contexte Reveal.js fourni par `LayoutSlides.astro`. Ce layout inclut déjà `UiDeck` : ne pas imbriquer un second deck.

| Composant          | Props               | Slots                    | Rôle                                                                                                                  |
| ------------------ | ------------------- | ------------------------ | --------------------------------------------------------------------------------------------------------------------- |
| `UiDeck`           | Aucune              | Par défaut               | Conteneurs `.reveal` et `.slides` autour des diapositives. Utilisé dans les layouts de présentation.                  |
| `UiChapter`        | `id: string`        | Par défaut               | Section de chapitre avec une ancre unique ; attend des diapositives enfants, navigables verticalement dans Reveal.js. |
| `UiSlide`          | `title?: string`    | Par défaut, `notes`      | Section de diapositive ; affiche un `h2` si le titre est non vide.                                                    |
| `UiTwoColumnSlide` | `title?: string`    | `left`, `right`, `notes` | Section à deux colonnes égales, centrées verticalement, sous un éventuel `h2`. Aucun slot par défaut.                 |
| `UiNote`           | Aucune              | Par défaut               | Notes Reveal.js dans un `aside.notes` ; enveloppe le texte seul dans un `p` et conserve le HTML fourni.               |
| `UiCode`           | `language?: string` | Par défaut               | Bloc `pre > code` avec `data-trim` et classe `language-{language}` si renseignée.                                     |

### Diapositive et notes

```astro
<UiChapter id="introduction">
  <UiSlide title="Objectifs">
    <p>Comprendre les besoins des utilisateurs.</p>
    <UiNote slot="notes">Demander les attentes du groupe.</UiNote>
  </UiSlide>
</UiChapter>
```

### Deux colonnes

`UiTwoColumnSlide` crée une slide complète et contient déjà la balise `<section>` : l’utiliser directement dans le diaporama ou un `UiChapter`, sans l’entourer d’une autre section de slide. La propriété `title`, lorsqu’elle est non vide, crée un titre `<h2>` au-dessus des deux colonnes.

```astro
<UiTwoColumnSlide title="Comparer">
  <Fragment slot="left">
    <h3>Avant</h3>
    <p>Le contenu initial.</p>
  </Fragment>
  <p slot="right">Le contenu amélioré.</p>
  <UiNote slot="notes">Expliquer les différences.</UiNote>
</UiTwoColumnSlide>
```

`Fragment` regroupe plusieurs éléments dans un slot sans ajouter de conteneur HTML. Placer les notes dans `notes`, en dehors des colonnes. Le composant occupe toute la hauteur de la slide ; vérifier les débordements. Bien que son interface étende `HTMLAttributes<'section'>`, seul `title` est utilisé : `id`, `class` et les autres attributs ne sont pas rendus sur la section.

### Code

```astro
<UiCode language="html">{'<button>Valider</button>'}</UiCode>
```

Pour un exemple sur plusieurs lignes, utiliser `is:raw` :

```astro
<UiCode language="html" is:raw>
  <label for="name">Nom</label>
  <input type="text" id="name" name="name" autocomplete="name">
</UiCode>
```

Passer le code comme texte pour afficher les balises. La coloration dépend de l’intégration Highlight de Reveal.js et de ses langages disponibles.

- [Documentation des blocs de code dans Reveal.js](https://revealjs.com/code/)
- [Liste des langages pris en charge par Highlight.js](https://highlightjs.readthedocs.io/en/latest/supported-languages.html)

## Éléments de page

| Composant           | Props                                                          | Slots      | Rôle                                                                                                                                                                                                |
| ------------------- | -------------------------------------------------------------- | ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `UiHead`            | `title: string`, `description?: string` (défaut : `AnySurfer`) | Par défaut | Élément `head` avec titre, métadonnées, favicon et `robots="nofollow, noindex"`. Le slot ajoute des éléments au head. Utilisé dans tous les layouts.                                                |
| `UiHeaderLogo`      | `lang?: 'fr' \| 'en' \| 'nl'`                                  | Aucun      | Logo et texte alternatif localisés ; lien vers la racine du site tenant compte de `BASE_URL`. Utilise sinon `Astro.currentLocale`, puis le français en repli. Utilisé dans les layouts hors slides. |
| `UiFooter`          | `class?: string` (défaut : `site-footer`)                      | Aucun      | Pied de page AnySurfer et lien vers son site, ouvert dans un nouvel onglet. La classe fournie remplace la classe par défaut. Utilisé dans les layouts hors slides.                                  |
| `UiSmallAnySurfer`  | Aucune                                                         | Aucun      | Nom AnySurfer en petit dans un paragraphe, avec des couleurs adaptées au thème clair ou sombre. Utilisé dans les diapositives de titre (`Title.astro`).                                             |
| `UiTableOfContents` | `title: string`, `chapters: { id: string; title: string }[]`   | Aucun      | Navigation ordonnée vers les ancres de chapitre ; aucun rendu si `chapters` est vide. Utilisé dans `LayoutSyllabus.astro`.                                                                          |

```astro
<UiTableOfContents
  title="Sommaire"
  chapters={[{ id: 'introduction', title: 'Introduction' }]}
/>
```

Chaque `id` doit correspondre à une ancre existante. Le composant utilise l’identifiant fixe `syllabus-toc-title` pour son titre : ne l’insérer qu’une fois par page.

## Page de ressources

`UiTrainingResources` reçoit une prop `training` contenant les métadonnées et les `sections` du JSON. Il inclut `Layout.astro` et génère le menu, les ancres et la numérotation des sections visibles. Les listes vides sont masquées. Les données sont validées par `src/lib/training-resources.ts`.

Le slot `heading` personnalise le titre de page avec un `<h1>` ; les autres slots sont nommés dans les données pour accueillir du contenu Astro spécifique. Consulter le guide **Actions courantes** pour le format JSON.

```astro
---
import training from '@data/intro-training-resources.json'
---

<UiTrainingResources training={training} />
```

## Catalogues de formations

| Composant                  | Props                         | Slots | Source et comportement                                                                                                                                                                                              |
| -------------------------- | ----------------------------- | ----- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `UiTrainingList`           | `lang?: 'fr' \| 'nl' \| 'en'` | Aucun | Tableau `trainings` interne au composant ; liens vers les diaporamas et leurs syllabus. Sans `lang`, affiche toutes les langues disponibles ; sinon filtre la liste. Utilisé dans les pages d’index des diaporamas. |
| `UiTrainingResourcesIndex` | `lang: 'fr' \| 'en' \| 'nl'`  | Aucun | Page complète avec `Layout.astro` ; filtre `src/data/training-pages.json` par langue et trie les ressources par titre. Utilisé dans les pages d’index des formations.                                               |

```astro
<UiTrainingList lang="fr" />
```

`UiTrainingResourcesIndex` s’utilise directement dans une page, sans ajouter un autre layout :

```astro
<UiTrainingResourcesIndex lang="fr" />
```

Les deux catalogues tiennent compte de `BASE_URL` pour les liens, mais ne créent pas les pages liées. Leurs sources sont distinctes : modifier l’une ne met pas l’autre à jour.

Référence : [composants, props et slots Astro](https://docs.astro.build/en/basics/astro-components/).
