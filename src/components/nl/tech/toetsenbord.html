Zie je waar je bent?

Terwijl je tabt, is de focus dan altijd zichtbaar? (- / +)

Focus stijl

Browserfocus nooit verwijderen:

a:focus { outline: none }

Voeg een eigen stijl toe of kopieer de hover-stijl

a:focus { color: #fff; background: #00F; }

Geraak je overal?

  • Zijn alle links, formuliervelden en knoppen bereikbaar met de tabtoets?
  • In een logische volgorde?
  • Niet goed: div onclick
  • Voorbeeld: de knop extra websites op de website van Dilbeek
  • Gebruik altijd a of button

Is tabvolgorde logisch?

  • De tabvolgorde = de volgorde van de elementen in de broncode.
  • Zorg er dus voor dat de volgorde in de broncode overeenkomt met hoe het er visueel uitziet.

Uitzondering: cookie banner

  • Vaak een overlay
  • Gebruiker wil die snel wegklikken
  • Plaats als eerste in de broncode

Is alles bedienbaar?

  • Werkt elke link met enter?
  • Een aankruisvakje met spatie?
  • En een knop met allebei?
  • Een keuzelijst met pijltjes?

Tabindex-attribuut

  • Attribuut dat tabvolgorde beïnvloedt
  • Enkel in specifieke gevallen gebruiken
  • Artikel over het gebruik van tabindex

Tabindex="0"

Een element dat standaard geen focus krijgt, kan je toevoegen aan de tabvolgorde met tabindex="0". 

<div class="customCheckbox" tabindex="0">

Tabindex="-1"

  • Haalt een element uit de tabvolgorde,
  • Maakt het element focusbaar via JavaScript (zie verder voor focus management).

Tabindex="1"

  • Met tabindex="1" (en hogere nummers) geef je een element voorrang binnen de tabvolgorde.
  • Af te raden want creëert meestal verwarring
  • Zeker als je elementen vergeet (slecht voorbeeld)

Enkel teken sneltoetsen

Als de website sneltoetsen voorziet:

  • ofwel kan de gebruiker die uitzetten
  • ofwel kan de gebruiker ze herdefiniëren
  • ofwel is de sneltoets enkel beschikbaar als de component focus heeft.

Voorbeeld

  • In de Youtube speler kan je pauzeren met de letter k
  • Dit werkt enkel als de video focus heeft, niet elders op de webpagina
  • Reden: website mag geen sneltoetsen van de gebruiker overschrijven
